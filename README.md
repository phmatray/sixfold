# PkmnTCG

A from-scratch, clean-room reimplementation of a Pokémon-style trading card game
in **Rust**, compiled to **WebAssembly** to run in the browser, with a modern
2026-era UI/UX.

## Scope & legal

- Original implementation of the game **rules and mechanics** (not copyrightable).
- **No** Nintendo/Game Freak/The Pokémon Company assets (card art, text, sprites,
  data tables) are included or redistributed. The reference ROM is git-ignored and
  used only locally for understanding mechanics.
- Card art and content in this project are original or placeholder.

## Status

Project bootstrapped. Game engine and UI not yet implemented.
